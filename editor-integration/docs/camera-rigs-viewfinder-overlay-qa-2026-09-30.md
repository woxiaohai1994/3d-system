# 原版控件在实时取景中的显示与点选

本轮是完整插件集成中的一项进展，不代表全部视觉、UI、操作已与 Blender 对齐。沿用仓库固定版本 Add Camera Rigs 的控件数据和骨架求值结果，新增实时取景控件图层。

## 实现

- 实时取景复用原版控件全部顶点、边、骨架矩阵、主题颜色、选中状态和线宽；不另画替代图标。
- 控件绘制在独立透明画布，实时照片画布仍只包含场景。照片与视频输出不执行控件渲染。
- “显示在前方”开启时穿透绘制；关闭时使用当前场景材质生成深度，再绘制控件。拾取沿用空间控件选择规则，并检测遮挡。
- 画面内点选接入原版姿态选择逻辑，拖动使用已统一的变换会话、活动工具、约束、旋转中心和撤销。
- 控件渲染保存并恢复共享渲染器状态；GPU 回读期间保存对应帧的相机与线框矩阵，防止下一帧姿态改变已显示画面的点选位置。切换相机后放弃旧回读。
- 透明线框回读转换为 ImageData 所需的非预乘颜色，保留半透明边缘颜色。只读、物体动画编辑、播放等不可操作状态隐藏图层。

## 实际浏览器操作

Google Chrome，`http://localhost:3002/scene/4d3b26be8028`，相机 1，滑轨相机架，24 毫米，透视，移动工具、质心中心。所有操作通过原生界面完成。

1. 选中“机位”，在实时取景内点击右侧瞄准箭头；活动控制骨由“机位”变为“瞄准”，两处界面同步。
2. 拖动箭头 `(3272,914) → (3372,854)`，瞄准局部位移由零变为 `[2.219,0,1.331]` 米。撤销后恢复 `[0,0,0]`。
3. 拍照并通过系统保存窗口存到 `/private/tmp/camera-rig-overlay-photo-qa-20260930.png`。打开导出的 1416×720 图片，确认只有场景、没有彩色控制线框。
4. 用 G/Y/-10、G/X/-15、G/Z/-15 临时将瞄准点移到地面遮挡范围。开启“显示在前方”时取景中心仍可见瞄准线框；关闭后消失。撤销临时变换与显示设置，位移恢复零，显示在前方恢复开启。
5. 点击 Chrome 的重新加载按钮，重新选择并双击相机 1 打开取景。原版线框重新出现；在新的面板位置点击 `(3272,1144)` 的箭头，再次从默认“机位”切换到“瞄准”。没有依赖热更新中的旧画布注册。

刷新后观察视口和三维光标回到应用默认状态。相机拍摄画面保持原状。未操作另一个建筑测试标签页。
