# 相机架工具与临时变换核查

## 原码依据与修正

`vendor/blender-keymap/blender_default.py` 的变换快捷键模板把 G/R/S 绑定到
`transform.translate`、`transform.rotate`、`transform.resize`。工具切换另用
`wm.tool_set_by_id`。因此一次快捷键变换不应改变工具栏所选工具。

宿主此前在 `rig-keyboard.ts` 结束手势时沿用了临时变换模式，随后
`rig-gizmo.tsx` 又将其写回工具栏状态。结果是在移动工具下按 R 后，再拖
控制骨会继续旋转。现保留手势开始前的工具，在确认、取消、失焦后恢复；
手势状态发布不再修改工具栏模式。原始键位及变换计算来源未改变。

`rig-keyboard.test.ts` 新增 16 个组合回归，覆盖移动工具下 R/S、旋转工具下
G、缩放工具下 R，分别通过回车、退出键、失焦、鼠标确认结束，再实际启动
下一次控制骨拖动，验证该拖动沿用原工具。该文件 49 项通过，295 个断言；
编辑器类型检查、三个修改文件的 Biome 检查及差异空白检查通过。

## 浏览器实际操作

Chrome 原生界面操作，测试页 `http://localhost:3002/scene/4d3b26be8028`，
相机 1，滑轨相机架，照片模式，时间轴关闭，未绑定物品，焦距 24 毫米。
没有操作另一建筑项目标签页。

| 操作 | 页面可见结果 |
|---|---|
| 移动工具，机位，R Z 30，回车 | 临时旋转完成后工具恢复“移动”；机位局部旋转约为 −20.498、−20.440、−5.314 度 |
| 随后拖机位箭头 | 位移变为 1.161、0.091、0.489 米；旋转通道保持上一行数值；一次撤销恢复位移零，再一次撤销恢复旋转零 |
| 移动工具，S 2，退出键 | 预览缩放为 2、2、2；取消后恢复 1、1、1，工具仍为移动 |
| 光标吸附瞄准点，中心选三维光标，选机位及旋转，直接拖机位线框 | 瞄准点屏幕位置固定，机位移到另一侧，取景画面更新；机位位移约 1.676、0.200、1.069 米；一次撤销恢复全部位移与旋转零 |
| 光标吸附机位，选瞄准及旋转，直接拖瞄准线框 | 机位中心屏幕位置固定，瞄准点移到机位另一侧，相机转向及取景更新；瞄准位移约 1.730、−0.224、−1.200 米；一次撤销恢复全部位移与旋转零 |
| 旋转工具，瞄准，G X 1，回车 | 位移按世界 X 改变，局部通道约 0.707、−0.642、−0.295 米；确认后保留旋转工具；一次撤销恢复位移零 |

现场拖动通过真实线框命中触发，未用脚本直接修改页面状态。以上数值来自
页面控制参数，环绕结果另观察了空间控件及取景画面。它们证明当前测试
路径可操作，不证明所有架型、所有姿态或所有原生选择模式已经完全对应。
