# 相机架取景交互接入与验证（2026-09-30）

本轮接通取景画面与场景控制骨的同一套变换。整个原版兼容目标仍未完成；以下仅记录本轮实际修改及证据。

## 修改

- 原取景操作强制选择 Camera 并使用独立移动／环绕算法。原版相机架现在通过 `beginRigWidgetDrag` 进入 `CameraRigGizmo` 注册的同一 `bindRigKeyboard` 控制器，沿用所选控制骨、多选、活动工具、旋转中心、方向约束、数值输入、源通道锁和事务。
- 取景面采用当前拍摄相机及有效画幅的输入坐标；场景面仍使用观察相机。结束或取消后恢复观察相机，避免下一次场景操作继续使用取景坐标。
- 相机架的右键、中键、滚轮不再绕过选择直接改 Camera。自由相机保留现有移动、环绕、推拉操作。原版相机视图的纯视图缩放／平移尚待接入，不能把此项视为完整视图导航兼容。
- 中文提示显示当前控制骨、工具、世界／局部约束及确认／取消方式。
- `compile-transform-projection.py` 校验已固定上游源码的哈希，并提取 `view3d_project.cc` 的变换中心投影和 `transform.cc` 的失败回退。旋转／缩放与双向箭头使用该处理，覆盖零深度、相机后方和溢出情形。箭头保留源码的近零裁剪行为。

## Chrome 实际操作

使用原生浏览器界面操作 `http://localhost:3002/scene/4d3b26be8028`，相机 1、滑轨相机架、24 毫米、不绑定物品，时间轴关闭。未操作另一建筑场景标签页。

1. 取景中左拖瞄准点：局部位移变为约 `[2.663, 0, 1.331]`。切换检查机位，机位位移／旋转仍全部为零，缩放为一。撤销恢复瞄准点。
2. 取景中旋转瞄准点：局部 Y 旋转约 `49.031°`；撤销恢复。缩放拖动产生约 `1.959` 的三个缩放分量，撤销恢复。
3. 原工具为缩放，取景聚焦后输入 `G X 1`：瞄准局部位移约 `[0.707, -0.642, -0.295]`；退出键恢复位移及原缩放工具。
4. 光标吸附到瞄准点，旋转中心选择三维光标，选机位，在取景中输入 `R Z 30`：机位局部位移约 `[-2.085, 0.787, 3.281]`。确认后检查瞄准点，位移／旋转保持零。画布聚焦后撤销恢复机位。
5. 光标吸附到机位，选择瞄准点：自由旋转拖动绕视角轴产生约 `-20.898°` 的瞄准局部 Y 旋转，撤销。随后 `R Z 30` 使瞄准局部位移变为约 `[2.085, -0.787, -3.281]`；退出键恢复。截图观察到取景窗口中的黑色双向箭头和虚线。
6. 收尾逐项检查机位与瞄准点：位移／旋转均零，缩放均一。恢复瞄准单选、移动工具、质心。三维光标保留最后一次吸附位置，属于暂存编辑状态；未改动场景对象。

原生下拉菜单在浏览器未前置时未响应键盘选择；通过窗口的 Raise 操作前置后可正常使用。撤销时需将焦点移回画布，输入／下拉框焦点下不能据此判断场景撤销失败。
