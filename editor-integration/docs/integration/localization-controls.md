## 本轮接入

- 对象浮动操作菜单：目录定位、移动、编辑网格、组合/解除组合、弯曲、复制副本、开孔和删除，包含 title 与 aria-label。
- 多选面板的操作按钮、所选数量标题和会话组合说明。
- 楼层浮动列表：拖动排序、层高、复制、粘贴、删除、增层、插层和单元聚焦提示；复制楼层的四种预设及说明；删除确认。
- 楼层默认名仅在展示层按语言生成，浮动列表与场景侧栏共用 localizedLevelName。沿用原始零起算语义：0 为首层，正数为地上 N 层，负数为地下 N 层。显式用户名称原样保留，包含恰好叫 Ground Floor 的名称。
- 浮动楼层与侧栏重命名输入在 isComposing 或 keyCode 229 时不处理 Enter/Escape。这里修复两个输入入口，不代表全部快捷键的中文输入法验收已经完成。
