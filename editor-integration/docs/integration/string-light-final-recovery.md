# 灯串附着失效与恢复验收

2026-09-21。本次范围是图片和后续视频参考。用户确认灌木近似分布即可，因此不继续逐枝叶贴合、精确碰撞或形状约束。

## 生产页面操作

使用本地生产构建、临时 3004 服务和原生页面控件，在验收场景 `a1e71b066b2c` 操作；未直接写场景存储。

1. 基线版本 59：双坡屋顶；直线屋檐灯串有 40 个挂点，灯泡尺寸 0.050 m、灯距 0.300 m、暖色、追逐模式。
2. 将屋顶切换为平顶。灯串显示附着表面已改变、需要重新吸附的提示，保留原有灯串参数。
3. 快捷沿路径贴合遇到碰撞，显示失败提示并拒绝提交。
4. 使用「整串移动到点击的模型表面」放到平顶。40 个挂点全部重新绑定 `roofType=flat`，只改变位置、路径和挂点绑定，其他参数保持不变。
5. 首轮发现成功后此前快捷贴合错误仍显示。插件 `surface-move-preview.tsx` 在成功提交后清空创建器的旧错误，失败时仍保留有效错误。
6. 重新生产构建，重复上述完整页面流程。版本 65 确认 40 个平顶绑定；附着失效和旧碰撞错误均不再显示，控制台未捕获错误。
7. 两次原生 Cmd+Z 撤销移动与屋顶变形。保存版本 66 的整个场景图与版本 59 基线完全相同。临时页面与服务随后关闭。

## 适用边界

本次证明了一个真实屋顶拓扑变化的可见失败与恢复流程，不代表任意模型替换都能自动延续原附着关系。复制按钮和整楼层复制已有页面证据；键盘复制粘贴被测试工具的虚拟剪贴板拦截，未宣称该输入路线通过页面验收。灌木接受近似；灯光用于视觉参考，不是照度或物理绳索模拟。
