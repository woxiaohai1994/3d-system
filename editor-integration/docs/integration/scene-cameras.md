# 独立场景相机

入口：底部工具栏的「场景相机」。可从当前观察视角添加多台相机；相机作为独立节点随场景保存。默认面板宽 340 px，常用操作、比例和拍摄按钮直接显示，详细参数收进标题栏设置按钮；取景打开时不再重复显示另一份相机属性面板。

## 操作

- 编辑器的平移、环绕与缩放只改变观察视角；拍摄机位独立。
- 选中画布相机可见机身、取景锥及三轴手柄。G 切换移动，R 切换旋转，支持世界／自身坐标。拖动一次只提交一次历史记录，Esc 取消。
- 自由移动：位置与朝向分别调整。锁定对象：移动时持续瞄准目标，旋转手柄围绕目标移动机位。目标可从列表选择或在画布点选；此目标与景深对焦点独立。
- 「画面操控」开启后：使用主画布的共享导航：左键／中键拖动平移、右键旋转、滚轮缩放，双指缩放与平移、三指旋转。鼠标移入画面后可用 WASD 移动；空格＋左键也可平移。自由模式围绕当前观察点旋转、滚轮朝鼠标位置缩放；锁定模式持续朝向选定对象并围绕目标缩放。标题栏负责移动窗口，最小化不停止录制。
- 「使用当前画面」保存实际观察镜头的位置、方向、投影和构图，包括透视与正交视图。默认保持画布比例。已有相机架保留类型，按当前画面重建机位、瞄准及构图边界骨骼，解除旧物品瞄准绑定、清除旧本体偏移；后续直接操作这些控制骨，整个更新可一次撤销。
- 添加相机始终继承当前视图的位置、朝向和投影，不再回退到固定初始位置；创建后默认开启画面操控与飞行。
- 「画面操控」提供环绕／飞行两个按钮。飞行时右键原地转头，WASD 按镜头方向前后左右移动，Q/E 升降，Shift 四倍加速；Esc 取消本次未提交移动。切换到飞行会解除对象锁定。
- 「实时传输」由独立镜头跟随主视图的位置和朝向，开启时继承当前构图。相机焦距独立，变焦只改变取景范围，不改变任一机位、主视图镜头或世界对象；录制期间也可调焦距。输出排除全部相机辅助图形，主画布正常显示。关闭传输时保留最后机位与调整后的焦距。这是本地取景与录制，不涉及网络推流。
- 比例使用「画布、16:9、4:3、1:1、9:16」按钮。继承的构图按固定比例居中取景，调整焦距后按镜头与输出画幅重新投影。录制期间锁定输出尺寸与比例，不因编辑窗口尺寸改变而移动机位或拉伸视频；焦距仍可手动调整。
- 外层焦距快捷条支持 8–800 mm 输入与拖动；改变焦距同步更新取景锥与图像。正交相机显示取景高度。
- 景深开关启用光圈和对焦控制，可填写对焦距离或点选画面中的表面。
- PNG 照片；720p／1080p 实时视频、24／30 fps 目标帧率，优先 MP4，浏览器不支持时使用 WebM。视频没有音轨。

## 实现与边界

- 主画布和取景使用同一 `EditorCameraControls` 控制器（基于 `CameraControlsImpl` 引擎）及 `lib/camera-navigation.ts` 的手势、键盘速度和快捷键作用域。交互规则只在共享模块修改；两个控制器分别操作观察相机与场景相机，取景写入单次撤销记录。

- 锁定对象只为共享控制器设置固定中心。平移依然移动机位，控制器在自身缓动过程中保持朝向中心；移除锁定恢复自由导航与鼠标定点缩放，不在输出画面后另行修正朝向。
- 平移沿屏幕平面移动，按当前窗口像素和镜头投影换算，不再按小窗口比例减速。按下时拾取可见物体表面深度，在本次手势内保持该深度，让抓取点跟随鼠标；未命中表面时使用导航中心平面。相机辅助图形不参与拾取。锁定模式仍优先保持朝向目标，因此不承诺抓取点的屏幕位置不变。
- 拖动缓动设为零；共享控制器补齐瞬时移动可能跳过的 rest 事件，保证松手提交、撤销和等待中的过渡正确结束。程序触发的视角切换仍保留平滑过渡。旋转继续按窗口与焦段校准；长焦降低旋转速度。
- 快照继承观察镜头的导航中心距离并随场景持久化，连续操作与切换窗口保留导航中心，对焦设置不参与导航。环绕模式与主视图共享导航规则；飞行模式扩展为原地转头、沿视线前进及垂直升降，不受地面俯仰限制。
- `scene-camera` schema 存储位置、旋转、镜头、画幅、投影、裁剪范围、导航距离、景深、对焦和锁定目标。场景加载时为旧相机补齐新增字段默认值，保留原来的机位与镜头参数。目标引用声明在节点注册信息中，参与系统的引用重映射。
- 3D 编辑器和取景共用渲染器，取景使用独立镜头、RenderTarget 和景深管线；GPU 回读输出至独立 2D canvas，用于显示、照片与录制。
- 可见取景在画面操控或实时传输期间跟随渲染循环刷新，不受录像 24／30 fps 的节流限制；GPU 回读仍最多一帧在途，不积压旧帧。实际响应速度仍取决于场景渲染和 GPU 回读速度。
- 拍摄期间排除相机机身、取景锥、变换工具、网格等编辑辅助图形，并临时恢复选中高亮的原始材质；共享状态在同步渲染后立即恢复。
- 实时传输与独立相机共用离屏渲染管线，只复制观察镜头的世界位置和朝向；投影使用相机自己的焦距和画幅。全部相机辅助对象只在输出渲染期间隐藏，并同步恢复；不再复制主画布或修改主镜头 FOV。实时位姿跟随不写历史，开启和关闭分别提交一次，焦距手势单独可撤销。
- 旋转灵敏度统一按固定 50° 光学参考校准；主画布和取景都使用实际有效 FOV，避免拿当前焦距与自身比较导致补偿失效。键盘移动按可见范围调整速度，长焦允许细微移动。
- 景深是实时后处理近似。视频帧率依赖场景性能，不是离线逐帧渲染。
- 本次实现没有增加关键帧时间轴、补间或离线帧序列导出；后续动画可驱动持久化相机字段和场景对象字段。

## 验证（2026-09-22）

- 61 项相关测试通过，包含独立实时镜头、8–800 mm 焦距与四种比例、主镜头投影和机位不变、飞行原地转头／沿视线移动／升降加速、新增相机继承当前视图、退出实时传输保留焦距。editor 类型检查通过。
- 浏览器对比 50 mm 和 85 mm：主画布构图不变，取景内容随焦距放大。实时录像中调至 120 mm，生成 720×820、66.0969 秒视频，页面解码 readyState=4。停止传输后 120 mm 保留。
- 飞行模式取景拖动后机位变为 (9.520, 10.267, 10.213)，一次撤销恢复 (10, 10, 10)。测试相机 3 保留在当前画布用于用户继续试用。

## 先前验证（2026-09-21）

- 39 项相关测试通过：共享导航、透视／正交构图与父坐标转换、比例裁切、保存重开、旧字段迁移、单次撤销、全相机隐藏恢复、录制成功／失败资源释放、GPU 回读行对齐。
- 跟手测试覆盖 54 组窗口尺寸、焦段、投影类型与 30／60／144 Hz 更新组合，连续拖动、反向及松手后屏幕误差均小于 0.02 px；另验证不同表面深度、真实拾取排除相机辅助图形、立即操控的 rest 收尾与程序过渡。
- 最新浏览器复测：抓取可见模型拖动约 60×40 px，机位在松手后提交；一次撤销恢复 X=0.367、Y=14.554、Z=-0.222，原景深设置保留，未见错误日志。
- core 构建、editor 与 nodes 类型检查通过；35 个相关源码文件 Biome 检查通过。
- 浏览器实测画布平移和环绕驱动实时录制；独立取景拖动后一次撤销还原位置；全部相机图形在实时画面中消失。
- 画布比例录像 892×720、28.688 秒；竖屏录像 720×1280、33.517 秒，均在页面成功解码（readyState 4）。竖屏录像覆盖了取景面板最小化期间继续操作主画布。
- 16:9、4:3、1:1、9:16 布局已检查，4:3 输出 960×720、1:1 输出 720×720；关闭传输后固定比例仍保留。
- 非标准宽度 GPU 回读曾出现斜向错行，已修复末行不含填充字节的步长判断并实测恢复正常。
- 删除本次新建测试相机后，原有两台相机保留；重新加载旧相机取景正常，拍照与录像按钮可用，浏览器未见错误日志。
