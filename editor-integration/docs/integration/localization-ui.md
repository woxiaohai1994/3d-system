# 源码汉化、多语言与隐藏提示检查

2026-09-20。按用户要求暂停 T05 和其他功能合并，优先推进中文及多语言。本文覆盖本轮 UI 实施和已执行验证；T15 包含未完成的整合生命周期工作，保持 IN_PROGRESS，不能用本轮语言测试替代完整整合验收。

## 实施范围

- 同一语言状态覆盖宿主、编辑器、专属节点面板、通用参数面板和六个固定版本插件。默认简体中文，支持 English，即时切换、刷新保留、跨标签页同步。语言选择器等待客户端就绪后开放，避免页面刚出现时选择未保存。
- 统一消息字典和类型化占位符；拆分主界面、插件、法律页面、内置目录及材质词表。补齐目录、导入检查、错误边界、场景列表日期、缺失场景页、条款与隐私页。
- 内置目录按资源身份显示中文并支持中英搜索；用户改名、用户物件、外部目录、协议 ID、schema 枚举和工程单位不做批量替换。主语言字典不进入 core。
- 数字输入与名称输入保护组合输入过程。默认楼层名称按语言展示，显式名称保持原样；切换语言不重置选择、展开面板或插件当前页签。
- 六个插件的源码改动以版本锁定、SHA-256 校验补丁持久化；根 postinstall 自动应用。未只把修改留在 node_modules 中。维护方法见 ../../patches/localization/README.md。

## 隐藏提示专项

用户反馈的根因是 ActionButton 直接显示配置里的英文 label。现在该显示边界统一本地化，并提供对应的中文无障碍名称。额外补齐二维/三维注册节点快捷操作、柜体操作禁用原因、单元警告、参考对象状态、测量提示和侧栏图标提示。

生产浏览器实际悬停检查了九个可用底部按钮：朝向北方、选择、区域、测量、删除、参考对象、向左环绕、向右环绕、俯视。逐个匹配对应按钮的真实 tooltip，避免将关闭动画中的上一条提示误计为当前结果。显示/隐藏动态状态也已本地化；快捷键字母保持原样。

另检查快捷键说明、底部显示弹层、楼层复制预设与删除确认、相机/绘制提示、目录和植物/街景/泳池/环境/插件管理界面。柜体和单元的条件提示经过源码排查与类型检查；不是每个对象的每种几何组合都已在浏览器逐一触发。

## 继续维护与边界

新增固定文案应先进入语言字典，再通过 `useI18n().t` 或 `I18nText` 渲染；参数使用命名占位符。注册元数据用 `label()` 在展示处翻译。不要对 DOM、模型属性或用户输入做全局英文替换。新增语言需要扩展 Locale 与对应词表，并验证占位符、偏好恢复和日期格式。

保留原文的内容包括用户名称、品牌、技术标识、未知外部服务响应、导入校验的可展开原始诊断以及上游工程报告数据。骨架插件的计算警告/报告叙述、道路清理的运行时详细说明仍存在未全部映射的上游英文，不将这类字段的完整汉化报告为完成。Windows、全部屏幕尺寸、系统真实中文输入法组合以及所有插件深层计算状态仍需专门验收；AC-UI-05 暂不标记全量 PASS。当前不恢复 T05。
