# 散布灯的公共附着与跟随

2026-09-21。本轮补齐“选中模型创建无电线散布灯”之后的持续跟随，不改灯泡产品尺寸、颜色顺序或随机种子。

## 公共能力

core 的 `PointSetAttachment`、`capturePointSetAttachment`、`resolvePointSetAttachment` 负责一组位置的附着和跨坐标系解析。源、目标使用正交 `Frame`；默认复用 `nodeSceneFrame`，调用方也可提供已有的二维临时坐标解析。捕获时复用各节点的 `PointAttachmentProvider`，无提供者时保存宿主局部位置以支持刚体跟随。解析只返回位置及失效索引，不缩放调用方绘制的几何、不访问 Three.js、不写场景或历史，也没有灯串类型判断。

灯串使用四个参考点表示散布区域的原点和三条单位方向。它们附着在所选模型上，随宿主移动、旋转、支持的缩放产生区域变换；每颗灯的确定性位置经过这一变换，灯泡实例仍用单位缩放。这样数量、区域尺寸、深度、随机种子修改仍可以正常重建分布，不必为每颗灯保存独立场景节点，也不必在每帧求解 2,000 个附着关系。

单独移动灯串会重新捕获参考点，之后仍跟随宿主；同时移动宿主与灯串不叠加两次位移。实时预览与提交都复用 core 的更新协调入口。二维、三维及复制快照使用同一位置解析，移动手柄定位于实际散布区域中心。

复制使用现有声明式引用重映射，新增声明 `scatterAttachment.nodeId` 及 `scatterAttachment.points.*.attachment.nodeId`。一起复制宿主时指向副本；跨容器单独复制灯串时冻结复制时的区域变换并解除外部绑定。保存数据仅包含数字、字符串和节点引用，schemaVersion 升为 4，旧场景新增字段默认 null。

## 边界

这是整体区域的仿射跟随，不是逐叶片贴合或树冠体积碰撞。当前实测范围为导入物件的位移、旋转、非等比缩放及内置树木的高度缩放。改变树种、随机生成拓扑或替换模型可能使变形绑定失效；失效时保持刚体参考并显示重新布灯提示，不混用部分失效的方向造成扭曲。删除宿主使用保存时的区域，不保证冻结删除前最后一帧。GPU 风摆不在此次范围内。
