# 实际几何范围与灌木页面复验

2026-09-21。修复公共 `getSurfaceBounds` 把旋转包围盒的空角、不可见材质和未绘制面算入模型范围的问题。现在在目标坐标系中对实际绘制三角面的顶点求范围，每个可用实例分别变换；复用已有表面源、图层和可见性过滤。没有增加树木或灯串类型分支，散布和缠绕调用方共同受益。

范围计算仍是模型网格的轴对齐边界，不是树冠实心体积、透明贴图像素轮廓或 GPU 风摆后的轮廓。计算发生在布置操作时，未加入逐帧扫描。旧灯串保存的范围不会被后台改写。
