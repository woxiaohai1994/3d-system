# 项目模型缩略图

项目列表 `/scenes` 在原有卡片中显示真实模型总览，保留项目名称、对象数、更新时间和打开项目的操作。桌面三列、窄屏单列，沿用现有背景、边框和排版。

## 生成流程

- `SceneGallery` 按视口附近的项目顺序生成缺失预览，同时只运行一个独立 iframe。
- `/scene/[id]/thumbnail-preview` 读取已保存模型，等待插件及场景渲染准备完成，再用 `BakeThumbnail` 输出图片。
- `project-thumbnail-framing.ts` 根据可见模型的包围盒取景，排除场地、容器、辅助相机等，使小模型也能清楚显示。
- iframe 使用独立场景状态和不写入的 Viewer 偏好存储，没有模型自动保存。离开列表时 iframe 卸载。
- 空项目显示“空项目”；生成失败或超时显示“预览暂不可用”，可点击“重试”，仍可正常打开项目。

## 缓存与接口

缓存位于 `PASCAL_DATA_DIR/scene-thumbnails`；若仅配置 `PASCAL_DB_PATH`，使用数据库父目录；默认是 `~/.pascal/data/scene-thumbnails`。

每个项目保存一份独立缓存，文件名使用项目 ID 的 SHA-256。缓存修订包含生成算法标识、模型 `version` 和 `updatedAt`，模型更新后旧缓存失效。列表只接受修订匹配的缓存，不回退到旧 `thumbnailUrl`；刷新后直接加载已生成图片。

`GET /api/scenes/[id]/thumbnail` 返回当前修订的图片，缺失返回 404。`POST` 接收图片二进制及 `revision` 查询参数，支持 PNG、JPEG、WebP，最大 2 MiB；上传前后检查项目修订，过期上传返回 409。

接口复用现有场景 API 的权限、来源和限流检查。图片使用原子写入与 `nosniff` 响应头。缩略图是派生数据，不调用模型保存接口，不修改模型图、版本、更新时间或项目排序。

## 验证

2026-10-06 在 `localhost:3002/scenes` 验证了 10 个有内容的历史项目及 1 个空项目，包含建筑、灯串、柱体和导入橱柜。刷新后 10 张图片均加载成功，没有生成 iframe；390 px 页面内容宽度为 390 px。

新增 7 项缓存和接口测试验证了持久化、项目隔离、修订失效、图片限制、来源检查，以及上传前后完整模型数据不变。连同现有保存会话和安全检查共 17 项测试通过，应用类型检查通过。
