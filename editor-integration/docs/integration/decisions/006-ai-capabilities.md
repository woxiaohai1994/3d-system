# ADR 006：统一 36 项允许工具与人类确认

状态：接受设计；来源工具清单已提取，产品工具尚未实现。

来源 56 项工具中，本期纳入 36 项、排除 20 项。以需求 manifests/ai-tool-scope.json 为范围，以 ai-tool-inventory.json 为源码证据；同一能力注册生成最终 prompt、schema、validator/dispatch 和中文 UI。排除工具返回 UNSUPPORTED_TOOL，不匹配近似名称执行。

batch_operations 不是本期另行暴露的工具。多个合法工具调用归一成受限 EditPlan；schema/描述不得暗示排除能力仍可用。未知/重复字段、非有限数值、越界值、缺失层级和不兼容资产必须明确处理，不把空操作当成功。

最多 3 次模型往返、每方案最多 50 操作、总时限 180 秒，配置化且测试上限。模型 confirm_preview 只表示候选就绪，不能获得用户确认权限。提交仅来自用户明确的界面事件，绑定项目/请求/revision 且幂等。

保留原宿主全部手动工具；AI 子集限制不影响人工功能。阶段上线必须如实展示未完成组，不把首个家具工具通过当成本期全部完成。
