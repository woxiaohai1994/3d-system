# ADR 007：服务端配置的 AI 传输边界

状态：接受设计；T03 路由调用链审计见 transport-audit.md，T11/T14 实现及运行验证待执行。

客户端只提交有界上下文、允许的任务参数和 requestId。服务端持有密钥、模型配置及允许的 provider 目标；不能由客户端任意 URL 驱动转发。场景修改仍由浏览器 SceneEditAdapter 经人类确认执行，服务端不改浏览器活动场景。

参考 Aedifex ChatTransport/StreamCallbacks 的解耦方式，替换 @aedifex 类型、完整工具表和 SaaS 字段。当前来源 chat 路由支持 request.signal，但 summarize 路径的完整校验/取消需要补足；流中异常不能只关流后被客户端当作成功。所有成功/失败/取消有明确终止状态，并绑定 projectId/requestId；旧回调不得更新新项目。

不照搬 OpenPlan 的浏览器 API key 存储。图像请求协议与聊天传输分别适配，截图与生成结果保持来源区分。超时后供应商是否已处理未知时返回不确定状态，不自动重发可能收费的请求；未配置时给出中文说明，不请求用户粘贴密钥到对话。

T11/T14 使用可控 mock 覆盖分片、畸形 JSON、断流、取消、重复事件、重放、超时和目标限制，再按用户提供的服务配置验收真实链路；本轮没有发起付费请求。
