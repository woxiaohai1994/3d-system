# ADR 004：复用宿主相机与截图，明确 PNG 编码

状态：接受设计，T10 待实现。

复用 CameraPose、现有 capture rig 和 snapshot pipeline。OpenPlan 相机、构图与生图提示词工作流适配到此入口，不创建另一套主相机或主 renderer，也不直接 dispose 共享场景材质。

宿主默认截图为 WebP、1920×1080、最大边 2048；保持原缩略图行为。整合 PNG 输出使用已渲染内容的独立实际编码路径，核对 MIME、签名、像素尺寸和透明背景，禁止仅改文件名。所有尺寸限制/裁切必须在 UI 体现。

截图开始冻结项目/revision、相机和展示配置；控制层/辅助线按现有呈现边界隐藏，finally 恢复。项目切换、失败或取消不得留下隐藏状态或额外相机控制。T10 以真实含 Environment 的场景验证，而非只对编码函数测试。
