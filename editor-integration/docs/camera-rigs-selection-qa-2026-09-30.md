# 相机架选择与组合变换核查

## 源码与集成边界

新增未修改的 Blender v4.3.0 `pose_select.cc`，来源与 SHA-256 记录在
`vendor/blender-pose-selection/UPSTREAM.json`。
`scripts/blender/compile-pose-selection.py` 校验来源后提取姿态点选的选择分支、
全选操作、父子控制骨变换标记遍历及移动不可用时转为旋转或缩放的分支。
生成代码接入控制骨线框命中与宿主选择状态。

复用的不是 Blender 整个事件系统：C++ 指针和链表映射为 TypeScript 对象和数组，
场景通知、射线命中、事务与渲染仍由宿主承担。原始相机架控制骨均不连接，
导出器对此作断言。不能将这些提取分支描述为整个插件的完整运行时移植。

当前实现区分活动控制骨与选中集合。Shift 点选已选但非活动的控件先激活它，
再点活动控件取消选择，保留活动指针。按下已选线框保留组合以供拖动；
没有拖动的普通点选在释放时切为单选。父骨带动子骨时使用源码标记排除重复变换；
各自原点旋转保留源码的子骨无位置变换规则。单选也走同一选中集合通道，
活动但未选中的控制骨不会被错误移动。各自原点的鼠标辅助中心使用质心。

选择更新同步到场景控制器，避免面板刚改变选择后快速按 G 仍操作旧集合。
Mac Option+A 的字符值是 å，使用按键代码映射回原版 Alt+A。
空选择仍占用相机编辑的 G/R/S，防止事件落到普通地形工具。
撤销架型切换后，已不存在的控制骨不再阻塞当前架型选择。

## 原生数值对照

`export-camera-rig-selection.py` 在 Blender 5.2.2 LTS 工厂环境运行原始插件，
生成 `add-camera-rigs-selection.json` 的 900 组案例：滑轨、摇臂、平面架；
五种中心；移动、旋转、缩放；初始姿态及父级旋转、非均匀缩放姿态。
包括多骨组合和单骨选中但活动骨未选中的情况。
比较所有可见控制骨的位移、旋转、缩放通道，容差 0.0002。
源代码版本为 4.3，原生测试程序为 5.2.2；这些案例通过不等于所有版本行为相同。

本轮最终检查：五个相关测试文件 57 项通过、324 个断言，包含上述 900 组
通道对照及既有中心变换案例；编辑器类型检查、13 个文件的 Biome 检查与
`git diff --check` 通过。生成脚本已重新运行并通过源文件哈希校验。

## Chrome 实际交互

测试页 `http://localhost:3002/scene/4d3b26be8028`，相机 1，照片模式，
时间轴关闭，未绑定物品，焦距 24 毫米。未操作另一建筑项目页。

| 操作 | 实际观察 |
|---|---|
| 机位与瞄准多选，拖动非活动瞄准线框 | 两个控制骨位移均为约 1.316、0、0.658；一次撤销恢复 |
| 两控件多选，R Z 30，再取消 | 瞄准位移、旋转预览改变；退出键后恢复零，移动工具保留 |
| 取消活动机位选择，立即 G X 1 | 机位保持零；瞄准位移约 0.707、−0.642、−0.295；一次撤销恢复 |
| 两控件多选，质心，S 2 | 机位与瞄准局部 Y 位移分别 −5、5；两者缩放均 2；一次撤销恢复位移零、缩放 1 |
| Alt+A 后 G、R、S | 所有控件取消选中；不启动变换，也不切换地形工具 |
| 从空选择 Ctrl+I | 四个滑轨控制骨全部选中 |
| 全选后拖动非活动瞄准箭头 | 整个架随动，活动机位保持；整体骨位移约 1.012、0、0.506；一次撤销恢复零 |
| 摇臂支柱升降，按 G，再输入 2 | 手势自动显示缩放；支柱 Y 比例及高度为 2，锁定的 X/Z 保持 1；取消后撤销架型切换 |

面板追加选择使用原生键盘焦点与 Shift+回车，实际拖动使用屏幕线框命中。
以上不宣称已经现场验证 Shift+鼠标组合按键、所有架型的全部指针手势或时间轴多选。
