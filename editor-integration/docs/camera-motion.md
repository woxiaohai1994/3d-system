# 场景视频时间轴

入口：底部「场景相机」→ 相机取景窗口「视频时间轴」。现有相机可直接使用，没有相机时先从当前视角添加。取景窗口保留「拍照」，原实时「开始录像／停止录像」及 MediaRecorder 管线已删除；视频统一由时间轴导出。

## 使用流程

- **仅拍摄场景动画**：总时长设为 5 秒，不加相机或物品关键帧，便可预览、导出灯串闪烁等已接入共享时钟的动画。相机保持当前机位。
- **物品运动**：主画布选择物品 →「为选中物品添加关键帧」→ 移动播放头 → 用动画坐标轴或位置/角度输入调整姿态 →「记录物品关键帧」。选中已有帧时显示「更新物品关键帧」；取消草稿恢复该时刻的已存姿态。记录的是物品局部位置与旋转，不修改布置状态。
- **统一时间轴**：相机和物品共用播放头、刻度、总时长。直接拖动任一关键帧改时间，保留它的位置、朝向和标识；按帧吸附且相邻帧至少隔一帧。首帧也可后移，首帧前及末帧后保持端点姿态。总时长不能短于最后一个关键帧。
- **缓动**：选中物品关键帧（作用于到下一帧的段），或相机关键帧的「缓动与运动路径」，选择匀速、缓入、缓出、缓入缓出；拖动曲线的两个控制点或修改 X1/Y1/X2/Y2 可自定义。横轴是时间进度、纵轴是运动进度，范围 0–1。物品轨迹为相邻位置之间的直线，曲线控制速度；相机另保留平滑路径和环绕。

相机操作：

1. 在 0 秒点击「添加镜头点」记录 A。可以先「取主画布机位」，或在拍摄画面中「漫游找机位」。
2. 将播放头移到 3 秒，移动机位，再添加 B。相机移动只产生草稿；选中已有点时必须点击「更新镜头点」。取消草稿恢复已保存构图。
3. 漫游沿用右键转向、WASD 移动、Q/E 升降、Shift 加速。速度可调；Esc 释放操作并保留草稿。视角大小仅改变构图。
4. 选中 A 关键帧，再点「缓动与运动路径」编辑到 B 的路径、节奏和看向方式。可以绑定已选对象中心，也可点击「点选注视点」再点击主画布中的屋檐等表面；局部 XYZ 偏移可调。环绕中心单独设置，没有已选对象时直接进入表面拾取。环绕预设生成 45° 的下一段，仍可编辑端点与方向。
5. 播放、暂停、拖动播放头检查。镜头点支持复制、删除、拖动时间、名称、位置/朝向数值微调、视角大小。
6. 相机轨道、物品轨道和切换标记统一保存在场景时间轴中，使用现有自动保存和撤销/重做。选择 720p/1080p、24/30 fps，导出无声 H.264 MP4，再手动导入视频生成工具。

## 时间轴界面

参考 [Blender Dope Sheet](https://docs.blender.org/manual/en/5.0/editors/dope_sheet/introduction.html) 的通道与关键帧布局：左侧固定对象轨道名称，右侧共用标尺、网格和贯穿轨道的播放头。相机与物品均使用菱形关键帧；选中为黄色，取消原相机缩略图卡片和独立播放滑块。

- 拖动标尺定位，左右方向键逐帧移动，Home/End 跳到首尾。
- 拖动菱形调整时间，自动吸附到帧；Esc 或失焦取消本次拖动，松手后产生一次撤销记录。焦点在关键帧上时 Delete/Backspace 删除关键帧。
- 工具栏可跳转上/下关键帧、首尾、缩放时间轴和适配全段；放大后可横向滚动，轨道名称保持固定。纵向滚动时标尺保留在顶部。
- 相机选中关键帧后进入「缓动与运动路径」；物品关键帧直接显示到下一帧的缓动。动画数据、共享采样与视频导出不变。

## 多相机交互与导出

- 所有相机列在同一时间轴中。点击相机轨道编辑它的位置、朝向和路径；选择轨道不会自动改成片的拍摄相机。
- 「拍摄 → 按切换标记成片」使用起始相机，遇到标记切换到绑定相机。将播放头移到指定时刻，选中相机轨道，再点「在此切换到编辑相机」。相机切换行用三角标记表示；可拖动改时间，也可选中标记修改时间、相机或删除，支持撤销和 Esc 取消拖动。
- 「拍摄 → 指定相机整段」始终从指定相机观看同一段共享动画。可分别选择 A、B 手动导出各机位；尚无一键批量导出。
- 「预览编辑相机」明确切到指定相机模式，预览与导出使用同一拍摄方式。需要恢复剪辑成片时切回「按切换标记成片」。漫游取景只在当前拍摄相机与编辑相机一致时可用。
- 物品运动、灯串等继续使用同一绝对时间，不因切镜头重播。相机切换是直接切镜头；单台相机的运动仍按它自己的关键帧与缓动求值。透视和正交相机可混用。
- 「画幅与轨道管理」设置整个视频的画幅。默认沿用首次打开时间轴的相机画幅，各机位都用统一画幅渲染，视频尺寸不会在中途变化。已删除的拍摄相机会显示缺失并清空取景，须修复标记或指定其他相机；父级改变的轨道须移除后重建。
- 首次打开旧项目时间轴时，将旧相机路径和物品动画导入场景级时间轴，原相机 `motion` 数据保留为迁移前记录，后续编辑以 `site.animation` 为准。同一物品存在不同旧版本时，首次打开的相机优先；所有冲突原始版本保留在「旧动画存在不同版本」中，可明确恢复为共享轨道并撤销。混合旧帧率采用 30 fps，避免较密的旧关键帧被拒绝。

## 明确的编辑规则

### 大画面预览

- 时间轴播放按钮旁的「预览模式」进入全窗口观看，隐藏编辑界面与辅助线。进入时保留当前播放头和播放/暂停状态；已有草稿、拖帧、拾取或导出未结束时不能进入。
- 「时间线切镜」按相机切换标记呈现；「单机位」可选择任意相机观看整段共享动画。播放中切换机位或观看方式不重置时间，也不改变正在编辑的相机轨道。这里与小取景窗、导出共用拍摄方式，退出后保留选择。
- 底部进度条按帧定位，定位后暂停；空格播放/暂停，左右方向键逐帧，Home/End 跳到首尾。在末尾点击播放会从头开始。Esc 或「退出预览」暂停在当前时刻并恢复编辑界面，编辑视角保持不变。
- 预览采用 720p 干净取景与统一视频画幅，等比适配窗口并保留黑边；不会把画面拉伸或裁剪填满。预览沿用共享时钟和导出取景管线，实际流畅度取决于场景与设备性能。

### 关键帧与轨迹

- 关键帧的 `time` 决定段时长，独立 `duration` 决定没有运动时的拍摄时长或片尾保持时间。拖动按帧吸附，相邻点至少间隔一帧，不能交叉。每轨最多 200 点、最多 100 条物品轨道、总时长最多 600 秒。
- 在段内添加点采用当前求值构图。插入、复制、删除后，仍相邻的旧段保留规则；新形成的相邻关系重建为默认平滑段。不会承诺拆分后精确保留旧曲线；界面提示复查。
- 默认连续通过，不对每段套慢入慢出。平滑路径用共享接点速度；直线/环绕在连续模式下允许接点附近有小段偏移，换取位置和速度连续。过渡区可调 5%–45%。
- 匀速模式按采样弧长分配位置，段内近似匀速，段间不承诺速度连续。选择缓动曲线后按曲线分配运动进度。完全反向、零距离等退化情况会减速，应补充中间点。
- 自由朝向使用四元数曲线和共享接点角速度，沿短路径过渡；自由朝向与看向约束交接使用共同的边界朝向，过渡区内逐渐接入约束。因此约束切换处允许短暂偏离严格瞄准。目标约束控制朝向时，点的自由旋转和漫游入口禁用；位置和镜头可继续微调，可修改注视点或明确将相邻段切回自由朝向。
- 轨迹线、预览、导出使用同一求值器。主画布显示当前拍摄相机和视锥方向。环绕中心与看向目标分别保存；相机不会自动挂在目标下。锚点保留稳定对象标识、对象局部坐标、局部偏移和绑定/调整时的后备位置，跟随对象旋转、缩放及父级变换。目标缺失后使用后备位置并提示重新绑定。
- 路径点使用相机父级的局部坐标，渲染时转换到世界坐标。没有自动避障、穿墙检测、重力或角色系统；由用户检查轨迹并调整。

## 渲染、动画与导出

- 视频时间轴编辑发生在三维画布；动画坐标轴独立于布置工具，不改变二维施工图。可录制具有三维 `position` 的场景物品（含导入物品、柱、块体及兼容插件节点）的整个对象位置与旋转；墙/板等以多边形或端点定义的结构不能直接作为位置轨道，缩放及内部开合不在本次姿态轨道内。
- 物品采样写入独立的临时姿态通道，按绝对时间同步应用到渲染对象，再计算相机目标和取景；不会逐帧写场景或堆积撤销。活动物品及其子对象退出静态合批，关闭/移除轨道恢复布置姿态。物品绑定父级发生改变后，轨道停用并提示重新添加，避免误用旧坐标系。
- 时间轴保存在场景根节点 `site.animation`：包含所有相机轨道、共享物品轨道、切换标记和统一输出设置。点击轨道选择编辑对象，不改变当前拍摄相机或播放时间；整项目复制会重映射相机、标记、注视目标、物品及父级引用。单独复制物品或楼层不复制场景级时间轴。

- 独立拍摄相机复用现有场景和 WebGPU 渲染器。编辑视图可继续观察场景；进入运镜时使用叠层和完整墙高，退出恢复原显示状态。
- 输出排除相机模型、路径、操作柄、网格、场地边界辅助线、扫描/参考辅助对象及选择高亮。沿用已有取景景深管线；并非主画布全部后处理效果的逐像素复刻。
- `sampleScenePlayback(seconds)` 让注册的程序动画按绝对时间取样。灯串闪烁/摆动、灶台火焰、屋顶风球及物品当前选中的模型动画已接入；暂停、倒拖、离线导出均采用相同时间。模型普通播放状态在退出时恢复。运镜期间 Three.js TSL `time` 统一取场景时间，退出恢复原更新器。环境天空/云、鸟群、灯塔、锦鲤、雨雪/闪电及泳池水波、瀑布、溢流、气泡现已另行适配其 CPU/GPU 时间源。
- 门窗/天窗、柜门、电梯、车道门及信箱等短动作仍属于原编辑器交互，**不记录为可重播事件**。正在执行动作或拖动物体时，导出会提示先完成操作；导出中若运行时交互状态改变，会中止并恢复编辑，避免生成依赖导出速度的结果。动作完成后的已布置状态可以拍摄。本轮按已确认的物品位置/旋转关键帧模型实现，不将鼠标点击自动转成门窗/电梯事件。添加新的持续动画模块时应注册绝对时间采样器。
- 导出采用 Mediabunny 1.59.0 + 浏览器 WebCodecs，固定 `i / fps` 时间戳，逐帧渲染、读回、等待编码。保留全部帧；复杂场景可以导得慢，不按墙钟录屏。仅在具备 H.264 编码能力的桌面浏览器可用，不静默降级为实时录屏。
- 导出时取得场景只读租约并停用机位操作；可取消，失败或取消后释放编码资源、恢复时间和编辑状态。资源加载期间禁用导出；视频缓存在内存中，长视频/高分辨率受设备内存限制。
- 尚未验证即梦对运镜参考的理解效果。此版不包含即梦调用、音轨、骨骼/网格变形编辑、灯光属性关键帧或自动录制门窗/电梯事件。

### 持续动画与恢复验收补充（2026-09-24）

| 动画来源 | 统一取样与退出恢复 |
|---|---|
| 灯串、灶台火焰、屋顶风球、GLB 当前动画 | 复用此前接入的绝对时间；GLB 恢复普通播放状态 |
| 环境天空/云、昼夜灯光 | 先天气，再天空，再实际灯光；按优先级同步求值，保存的时间设置不被播放改写 |
| 鸟群、灯塔、锦鲤 | CPU 姿态从绝对时间计算；暂停、倒拖和退出恢复有挂载组件测试 |
| 雨雪、闪电 | 雨雪 shader 共享时间；闪电采用固定种子和时间表，几何按实际拍摄相机定位，离线取样不播放雷声音效 |
| 泳池水波 | 固定 30 Hz 求解与确定随机扰动；倒拖重算。普通水面保留独立 GPU 状态，退出释放重播纹理并恢复 |
| 瀑布、溢流、气泡 | 私有 uniform 与实例矩阵按播放头取样，原实时循环在取样期间不累加 |
| 门窗、天窗、柜门、电梯及街景开关 | 完成代码审计，尚无事件轨道；导出检查未结束动作，并监测运行时变动 |
