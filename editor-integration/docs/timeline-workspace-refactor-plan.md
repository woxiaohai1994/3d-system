## 产品规则

- 物品、物品动画、材质、灯光、环境、插件配置全局共享。任意相机工作区编辑共享世界。
- 相机工作区可为空，手动创建后最多一台相机。每台相机只能归属一个工作区。保留自由编辑视角；时间轴只显示自己的相机与共享物品。
- 切换工作区保持世界源时间；成片独立保存播放位置。会话状态位于 editor，按 site ID 本地保存工作区、源时间、成片帧与选择；草稿不混入输出。
- 每两个相邻相机关键帧生成目录素材，镜头参数关键帧也参与，路径控制节点不参与。不足两个关键帧不产生新素材。
- 素材是实时源引用。双击片段进入源工作区并定位源时间。已使用来源独立保留，内部插入关键帧不会拆开已有成片片段；删除边界关键帧冻结其最后边界时间。
- 源内容同步画面，源时长变化不移动成片、重设速度或伸缩入出点。实例保存固定素材内入出帧；源缩短后的无效范围显示黑场，源延长可手动延长使用范围。
- 例：源 5–8 秒放在成片 20 秒，正常速度下成片 21 秒采样整个世界第 6 秒。
- 多轨上层完整画面覆盖下层；空隙露出下层；全空为黑场。普通移动和覆盖不会波纹移动后续片段。普通删除留空隙。
- 明确提供插入、覆盖、波纹修剪、波纹删除。各轨显示、编辑锁定、同步锁定（默认开）。波纹操作对跨越修剪点的同步轨道切开并同步修剪；锁定或源范围不足则整次拒绝。波纹删除不能删除其他同步轨道仍使用的画面。
- 删除工作区或相机先显示来源与实例数量；确认后一并删除引用，保留空隙，整次撤销。删除相机保留空工作区。
- 恒定速度百分比与倒放修改实例，不改源关键帧。速度面板可选择波纹移动后续片段，默认关。非整数倍速拆分保存采样相位，避免拆分跳帧。
- 叠化、黑场淡入、淡出默认一秒。叠化用于同轨相邻片段，居中剪辑点，不改变总长。两段三秒加一秒叠化仍六秒。优先使用源余量；不足时拒绝，用户可明确允许重复边界帧，转场保留标记。
- 第一版无外部导入、音频、分屏、画中画及任意嵌套合成。
- 成片使用整数帧、左闭右开区间；源时间仍为秒。MP4、24/30 fps、720p/1080p、项目画幅。更换项目 fps 按时间转换帧坐标。源保持 600 秒上限；成片按编排计算，独立于源时长上限。

预览和成片导出都调用 `renderFilmFrame`，由同一 `resolveFilmFrame` 解析来源。来源串行采样共享世界，各自完成渲染读回后立即合成，不并行写入世界、不复制持久化场景。相机和源时间明确传入；采样物品、属性、跟随目标、模型动画及着色器沿用世界采样入口。输出忽略未提交草稿，完成与失败均恢复编辑源时间。导出沿用只读租约、资源等待、场景变化检查及取消入口。

新文档只由 `sequence` 定义成片，不保存或读取旧 cuts 作为另一套成片输出。单相机预览和导出是源检查入口。

## 保存与迁移

读取 V1 时，先迁移再做 V2 校验。旧相机生成工作区，轨道及源时间保持不变；默认相机、切镜点和输出范围变为底层视频轨道。静态相机、非关键帧边界使用范围型来源，不插入关键帧。加载时把旧动画保留在 site metadata 的 `animationV1Backup` 中。

迁移失败保留原始动画并报告，编辑提交拒绝覆盖成空文档。自动保存仍保存完整 scene graph。相机删除、来源同步和片段删除纳入同一场景事务；撤销和复制覆盖新增记录。
