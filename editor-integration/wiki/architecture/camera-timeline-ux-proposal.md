# 相机与时间轴交互精简建议

状态：2026-09-25 已完成界面整合与 UI 优化技能复审。表格保留最初检查依据；实际落地范围如下。

## 已实施

- 时间轴只保留一个主要的“以当前视图创建关键帧”入口；普通添加/更新在相邻下拉菜单和轨道右键菜单中。物品轨道仍直接显示添加/更新。
- 相机属性按照片、时间轴、独立检查器区分，同一上下文只呈现一套焦距和位姿编辑；时间轴属性区只补充名称和景深。移除常驻 XYZ 微移按钮，精确坐标按需展开。
- 速度统一为平滑衔接、匀速、先慢后快、先快后慢、两端缓和。自定义曲线、精确控制点和衔接微调按需展开；已有曲线和过渡数值保持不变。
- 输出方式、机位、画幅、分辨率、帧率集中在导出旁的“输出设置”。点击切镜标记直接打开其编辑项；拖动标记仍只改变时间，不弹出编辑项。
- 小预览标题显示实际输出相机，关键帧/路径标题显示被编辑的相机，时间轴蓝色轨道表示激活状态。
- 减少常驻说明，保留草稿、目标缺失、导出错误等状态。旧段朝向、局部偏移、预览内漫游和照片实时传输作为对应上下文的次要操作保留。
- 注视和跟随保留在时间轴。默认中文名称、拾取光标、悬停与选中边框保持有效；物品轨道名称也复用同一中文名称解析。

## UI 优化复审后的工作区

- 时间轴采用底部操作栏和轨道区：播放、时间、逐帧导航、记录当前视图、输出设置与导出在同一栏。蓝色主按钮显示“记录当前视图”，悬停可见保存到哪个相机、哪个时间；普通添加/更新保留在相邻菜单。
- 当前相机、焦距、注视对象、拾取与跟随在轨道上方，构图微调用弹出层呈现，不把整个时间轴撑高。空轨道给出下一步操作提示。
- 取景窗与属性面板分别开关。属性默认收起；点击关键帧、路径或物品轨道时打开对应属性，右键“编辑关键帧”也能直接打开。精确坐标按需展开。
- 小取景窗显示输出相机，主画布左上仅保留当前相机和退出激活操作。取景窗收起时继续维护渲染画布，保持成片预览与导出可用。
- 时间轴可以收起轨道，仍保留播放、暂停与空格快捷键。浮窗与时间轴采用同一纵向布局，窄窗口允许操作栏换行，避免两个面板互相覆盖。

## 明确保留的行为与后续项

本次不修改动画模型、采样/导出算法、自动/手动保存规则：画布运镜仍手动记帧，原属性修改的记帧规则不变。
画面内拖动构图点仍是后续交互方案，目前通过“构图微调”的水平/垂直值调整。
旧照片预览导航和旧目标约束保留，避免已有使用方式和动画被直接删除；基础运镜仍以主画布操作为主。

## 结论

主要问题是同一种意图存在多套入口、编辑状态和术语，而不只是按钮太多。
应围绕“选相机 → 调画面 → 记关键帧 → 播放 → 导出”组织界面。
相机负责画面，时间轴负责时间；对象注视、跟随作为当前相机的上下文操作。
常用操作直接可见，选中关键帧或路径后才显示对应编辑项。不要把整个面板再包进一个“高级”抽屉。

## 推荐界面分工

- **相机区**：相机列表、从当前画面创建相机、进入/退出相机视角、焦距、拍照。重命名、复制、删除放在相机条目菜单，删除仍保留已有快捷入口。
- **时间轴**：播放/暂停、当前时间/时长、当前相机、创建关键帧、注视目标/拾取、跟随移动、轨道及关键帧。选中轨迹才显示路径/速度调整；选中关键帧才显示该帧的精确属性。
- **预览与导出**：单相机或时间线切镜、画幅、清晰度、帧率、导出。已激活相机播放时不显示相机模型和编辑标记；未激活时保留场景观察。

注视点和景深对焦点并不是同一个功能：注视决定朝向，对焦决定清晰距离。可以提供“对焦到注视对象”，但不要直接合并、联动或强制开启景深。

## 建议实施顺序

1. 先移除重复说明、统一“关键帧”术语，把常用入口放到对应区域，保留全部已有能力和保存行为。
2. 合并相机控制入口、焦距控件与注视设置，避免用户在不同面板编辑互相覆盖的值。
3. 用直接拖动和常用速度预设替代默认数值面板，再提供精确输入作为补充。
4. 最后统一自动/手动记帧规则。这是行为改动，应先明确决定，再迁移界面和测试。

验收以完整创作为准：构好特写、创建相机并记帧、选择主体保持构图、移动时间、拉远并记帧、播放与导出。整个基础流程不需要输入坐标、局部偏移、贝塞尔控制点或过渡百分比。


## 验证入口

- `scripts/camera-workspace-ui-browser.mjs`：三种窗口尺寸、取景窗与属性独立开关、轨道收起后的播放/空格、路径及右键属性入口、成片预览返回；面板操作不改动画数据。

- `scripts/camera-manual-view-browser.mjs`：单一主记帧入口、次要添加/更新、两种播放模式、切镜标记编辑与拖动、持久化。
- `scripts/camera-gaze-browser.mjs`：中文目标、拾取反馈、保持构图、跟随、手动记帧、透视/正交、取景窗隐藏时导出，MP4 解码与预览逐样本比对。
- `scripts/camera-path-edit-browser.mjs`：速度预设、按需曲线输入、路径拖拽、控制柄、端点不变、撤销与重做。
- `scripts/camera-path-orientation-browser.mjs`：旧路径朝向设置仍可编辑，重塑后保持目标，随机跳转与持久化。
- `scripts/motion-close-wide-browser.mjs`：特写创建相机、拉远记帧、旋转、空格播放、注视与焦距；照片设置不重复焦距，坐标按需展开。
