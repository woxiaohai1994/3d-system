# 3D 导演台整合与验收记录

本轮在现有相机、场景时间轴、Three.js 路径求值和 MP4 导出基础上实施。未安装依赖，未替换动画引擎。测试使用独立 Chrome 上下文和生成的场景副本，没有覆盖用户正在使用的项目。

## 已删除与合并

- 删除相机复制入口、实时传输状态与专用逻辑、相机 XYZ／旋转输入、独立小预览漫游及其草稿流程。关键帧复制、物品变换和相机删除保留。
- 创建／更新合并为一个上下文按钮，时间轴右键保留便捷操作。物品和相机遵守同一手动记录规则。
- 机位、镜头、对焦、注视、物品姿态和其他创作属性先预览，明确记帧才写入动画。切换时统一提供记录、放弃、继续编辑。
- 相机和物品共用画布路径组件，直线、曲线、端点、控制柄、整体移动和时间拖动分工明确。
- 注视和跟随共用一个目标，保留构图；构图微调使用画布拖动，对焦保持独立。
- 属性区按相机／物品／路径切换；进入时间轴收起建造侧栏，退出恢复。输出机位、画幅、分辨率和帧率集中到输出入口。

## 补齐能力

- 物品首次明确记帧后才建立轨道；选择和修改本身不偷偷创建关键帧。
- 圆形、方形与点选画路线直接生成可继续编辑的同一套路径。
- 插帧分割曲线和缓动；删除中间帧只拟合受影响片段，保留其他片段。
- 中文目标名、同名区分、拾取十字光标、悬停／选中边框、定位和清除。
- 直接拖动主体构图位置；跟随位移可叠加相机自身拉远。
- 主画布对焦拾取、对焦到注视点、连续对焦距离动画。
- 独立相机输出范围、可拖动总播放边界、可见切镜区间；编辑相机不改变输出配置。

## 兼容规则与边界

旧动画字段保留读取。旧物品轨道没有路径字段时沿用原来的线性／缓动运动；旧完整属性快照仍可读取。明确的关键帧注视优先于旧跟随／锁定，明确清除不会被旧约束重新覆盖。名称、分组等管理信息不再随旧快照播放。删除相机清理范围引用；复制整个项目时映射新的相机 ID。

删除中间帧后，一条三次曲线未必能精确表达原来的多段复杂路线，因此采用原路线三分之一、三分之二处拟合的确定规则，支持撤销。点选画路线先在当前高度的水平面上创建，随后可在三维视图调整端点高度。注视不包含自动避障；拾取对焦记录当前深度，不是额外的自动对焦绑定系统。

## 实际验证

- 浏览器完成相机和物品各两次手动记帧，确认焦距／画布移动不隐式写入，更新不改其他帧。
- 浏览器完成物品曲线、端点、关键帧时间拖动，检查几何与时间互不重置；完成撤销重做及保存重开。右键复制／删除关键帧及播放范围边界拖动通过，范围变化不改任何动画轨道。
- 浏览器完成正交相机主画布旋转／平移及两次手动记帧，再完成相机曲线、端点、整条路径移动和单次撤销。修复退出相机视角与路径定位之间的时序冲突。
- 浏览器完成注视保留画面位置、构图拖动、目标运动跟随和相机拉远叠加；对焦拾取不改变机位和朝向。
- 导出并解码 A 的场景第 1～3 秒、固定 B 的第 0～2 秒、含第 2 秒切镜的第 0～4 秒。时长分别为 2、2、4 秒；1280×720。抽样帧与预览 RGB 平均绝对差约 0.36～0.48／255。固定相机视频包含物品运动和动态灯串。
- 完成成片切镜预览和导出取消，取消后编辑／再次导出恢复可用。
- 独立静态场景的 1 秒转焦 MP4 解码后，近处区域清晰度指标约 11.87→4.51，远处约 4.89→10.08，中间五帧呈连续变化。这个场景使用柱体和灯串作为近远主体，不包含小女孩素材。

可复现脚本在 `scripts/director-*-browser.mjs`；运行结果、画面和 MP4 在 `.integration-audit/director-integration/`、`director-output/`、`director-focus/`。Core／Viewer／Nodes 构建类型检查、Editor 类型检查和差异格式检查通过；相关测试 98 项通过、0 失败、985 次断言。没有运行整个仓库测试集。

未覆盖：大规模复杂项目压力测试、所有浏览器／GPU，以及外部小女孩素材的具体构图。未对这些情况作通过声明。

## 任务书验收对应

| 验收项 | 当前证据 |
|---|---|
| 1. 相机／物品双关键帧、曲线、端点、时间 | `director-integration-browser.mjs` 和 `director-camera-browser.mjs` 实际操作与持久化断言 |
| 2. 手动记录、只改当前帧、管理信息独立 | 浏览器焦距草稿与更新断言；`motion-properties.test.ts` 和 `director-integration.test.ts` 属性通道／名称排除测试 |
| 3. 插帧／删帧保留路径、重开 | `director-integration.test.ts` 检查曲线分割、拟合与无关片段；浏览器保存重开比较整份动画 |
| 4. 注视、跟拍和拉远 | `director-output-browser.mjs` 检查多时刻主体投影、相机位移和独立构图调整 |
| 5. 固定相机动态场景 | 已解码 `camera-b-fixed.mp4` 并与相同场景时间的预览比较 |
| 6. 连续转焦、独立范围、成片切镜 | `director-focus-browser.mjs`、近远清晰度解码结果，以及 A／B／cuts 三个实际 MP4 |
| 7. 兼容、撤销、删除、进度与取消 | 旧字段／旧锁定／项目复制单元测试；浏览器删除撤销、重开、实际导出及取消恢复 |

界面采用 `ui-optimize` 的 Operate／distill 原则：主画布操作优先；右侧随相机、物品或路径选择变化；只保留一个主要记帧按钮；景深、其他属性和轨迹预设作为次级内容；输出设置集中。验收没有给用户场景写入测试内容。
