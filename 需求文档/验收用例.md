# 验收用例与通过标准

对应 INT-3D-BASE-001 v1.2。本文是待执行测试规范，全部初始 NOT_RUN。每个 PASS 必须写入 target commit、测试条件和证据。外部服务无凭据/无付费授权时写 BLOCKED，不计为本地通过。

## 统一判定

数据字段以源 schema 和本文适配约定为准。一般米制位置/尺度与弧度比较可采用 1e-5 量级容差；T03 应结合具体几何算法调整并解释。源文件 SHA-256、身份引用、集合、材质及插件状态按精确/语义完整比较。截图不能跨不同 GPU 使用无解释的逐像素相等；在固定测试条件下比较结构、图层和目标区域，动态插件使用测试冻结条件。

TOOLS 组每一行都含一个合法子例和一个非法子例，两个子例都通过才 PASS。非法用例优先选 source schema 明确拒绝且不会改变其他业务语义的边界；若宿主有合法自动修正，必须验证预览明确显示修正，不能把来源允许的行为误写成失败。

本地 MUST 未通过则不能称基础整合验收通过。macOS/Windows 双平台属于本地 MUST：AC-REGRESSION-03 和 AC-RELEASE-01 按主规范第 17.4 节拆分平台/浏览器子项，全部必需子项 PASS 才能标记父用例 PASS；平台环境缺失写 BLOCKED，未执行写 NOT_RUN（待验证），实测失败写 FAIL，不能豁免或算作外部凭据阻塞。EXTERNAL_AUTHORIZED 只有得到真实服务凭据与费用授权才执行；mock 测试不能替代它。
