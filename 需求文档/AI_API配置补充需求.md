# AI API 配置补充需求

AI-02 · 2026-09-20 · 用户追加要求：用户自行配置不同 API，兼容常用协议，并内置厂商模板。

- 在 AI 助手内管理多套 API 配置：名称、协议、基础地址、模型标识、密钥；可添加、编辑、删除和切换。
- 首批支持 OpenAI Chat Completions、Anthropic Messages 和 Gemini 原生协议；不将改地址等同于协议兼容。OpenAI Responses 与其他协议后续按实际需求扩展，不能宣称全部支持。
- 内置 OpenAI、DeepSeek、阿里云百炼（北京）、Anthropic、Google Gemini、自定义模板。模板预填地址和协议，不锁死模型，支持修改区域地址；用户填写账号可用的模型标识。
- 密钥只存当前服务端，不存浏览器持久化空间、场景节点、项目导出包或聊天记录；已保存密钥不回显。修改地址或协议后重新填写密钥，避免将旧密钥发往其他服务。
- 当前软件是本机单用户编辑器，配置属于当前服务；没有新增多租户账号体系，不承诺多用户凭据隔离。
- 保存配置不触发厂商请求；用户点击“测试连接”发起短请求并显示用量提示。验证文本连接不代表模型已支持场景工具。
- 切换配置时中止旧请求并清理待确认方案；模型错误、流中断、取消不得写入场景，不自动收费重试。
- 配置页、按钮、悬停提示、加载和错误状态接入原有 zh-CN/en 语言层。

验收：真实 UI 增删改切换与重开保持、三协议请求/流/工具夹具、密钥不回显与磁盘加密、同源与鉴权、过期配置冲突、取消和超时、无付费重试。真实厂商调用单列，用户未填写凭据不阻塞本地协议测试。
