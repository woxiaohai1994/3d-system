# 原生吸附、对齐和参考线接入

2026-09-22。

灯串创建、二维/三维挂点编辑和「移到表面」调用宿主已有的吸附与参考线接口。插件不复制对齐求解器，不新增参考线渲染器或面板开关。

## 复用接口

- `snapServices.grid`：公共网格量化。
- `collectAlignmentAnchors`、`resolveAlignmentForActiveBuilding`、`resolveAlignmentForFloorplanView`：场景候选点及二维/三维原生对齐求解。
- `useAlignmentGuides`：原生虚线、端点和距离反馈；沿用宿主显示与单位。
- `isGridSnapActive`、`isMagneticSnapActive`、`isAlignmentGuideActive`：读取当前交互模式，参考线显示与磁性吸附分别遵从宿主规则。
- `snapProfile: 'item'`：创建和整串移动使用物件模式入口，Shift 切换模式；已有偏好仍由宿主管理。
- `alignmentFootprint`：灯串把自身布局范围注册给宿主，普通整串移动和其他物品的对齐不需要灯串类型分支。
- `move-control-point` 和 `{ index }`：二维挂点使用宿主已识别的控制点操作名，统一进入/结束编辑状态。此前的自定义 `point` 名称不会激活吸附模式，这次页面复测发现并修复。

插件侧 `snapping.ts` 负责坐标转换、追加本条灯串已有挂点作为参考、排除当前灯串以及调用接口。候选集合按场景快照缓存；不在指针移动中重新生成相同候选集合。创建与提交使用同一个求解入口，预览不写历史。

表面命中后，对齐位置通过公共表面查询重新投影到同一个模型。若偏移无法落回原表面或跨过尖锐转角，则保留实际表面命中并清除不成立的参考线。取消、完成、卸载时清理临时反馈；二维控制点清理也复用宿主调度器。

## 验证

- 灯串相关回归 140 项通过、13,917 个断言；覆盖原有附着、移动、混合、灯效和产品参数。
- 最后补充无三维网格的二维坐标转换后，吸附与表面交互定向回归 16 项通过、109 个断言。含原生操作名到交互状态的完整映射、旋转建筑、楼层排除、表面保持、挂点历史、实际挂载绘制工具的预览/提交/收尾。
- 插件 TypeScript 与宿主生产构建通过。
- 本机页面 `4323f931cb8c`：创建时显示原生「吸附：参考线」。两个略有偏差的点击保存后 Z 均为 `1.0078047513961792`，证明第二个点吸到前一个点的轴线。
- 原生二维挂点拖动修复后，第一点从 `[-6.401601791381836, 2.5, 1.0078047513961792]` 落到 `[-5, 2.5, 1]`，遵从 0.5 m 网格。撤销拖动和新建后，版本 122 的场景图与版本 114 基线完全相同；页面未捕获控制台错误，临时标签已关闭。

本机临时日志：`/tmp/string-light-snapping-{tests,regressions,types,build}.log`；页面回读证据 `/tmp/string-light-snap-qa-{baseline,aligned,fixed-handle,final-restored}.json`。这些临时文件不是长期存档。

沿用系统平面 XZ 对齐，未新增任意三维方向或垂直高度对齐算法；原有轴向微调仍由宿主手柄约束。灌木保留用户确认的近似参考用途，不新增精细碰撞。
