# 灯串图标

`string-lights.png` 是透明背景的淡紫色立体灯串图标。由内置 imagegen 工具生成，参考宿主的 `apps/editor/public/icons/fence.webp` 材质和视觉风格。侧栏、插件列表、场景节点和属性面板通过 `src/icon.ts` 复用同一资源；图片随插件打包。

生成提示词：

> Create a single UI icon asset for a string-lights plugin in the Pascal 3D architectural editor. Reference image is STYLE ONLY: match its monochromatic pale lavender / periwinkle molded 3D material, soft studio lighting from upper left, clear beveled solid volume, isometric perspective, minimal product-model aesthetic. New subject: a short thick curved cable with exactly THREE large hanging S14 pear-shaped bulbs in molded lavender, one central bulb slightly lower, simple chunky readable silhouette at 24px. The bulbs and cable should be uniformly lavender, no yellow glow, no text, no lettering, no badge, no frame. Centered square composition with tight but safe padding, genuine transparent background and alpha channel, no floor plane or background shadow. Render as a polished 3D object icon, NOT a flat line drawing. Save output for use as the project's plugin icon.
