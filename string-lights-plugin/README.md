# 灯串插件 0.1

适配当前本地 Pascal 编辑器的独立源码插件。一个灯串是一个可选择、保存和撤销的场景对象；灯泡使用内部实例渲染，不把几百颗灯泡塞进场景树。

## 可以做什么

- **沿路径**：在二维或三维连续点击，每段立即保留；Enter、双击或 Esc 完成并直接选中灯串；支持跨物体和跨楼层挂点、拉直、下垂、柔和曲线、闭合路径和每段独立下垂深度。
- **缠绕**：底部/顶部半径、高度、圈数、起始角度、电线不规则度；适合树干、柱子等近似圆柱或锥形区域。
- **灌木随机**：在椭球或长方体区域布置灯泡，支持向内深度、密度和最小间隔；完全不生成电线。选中模型后可直接按实际几何范围布灯，并保存宿主关系；移动、旋转和支持的缩放通过公共附着接口跟随，灯泡本身保持固定大小。
- **外观与排列**：灯头独立选择 S14、C6 草莓壳、C9、迷你灯珠、银线灯珠或自定义 GLB；安装形态独立选择支线悬挂、灯座直连、左右支线、沿线居中；左右支线可逐颗交替、按比例随机或同点成对；固定尺寸和沿线灯距；自然程度总滑块、详细角度、随机种子和摆动；统一、交替、分组和渐变颜色，随机颜色仅智能款可用；常亮、呼吸、闪烁和追逐。
- **模型库**：复用内置和已发布的导入 GLB。保持灯座、夹子、地插等刚性几何；支持接线点、模型校准旋转、倍率和发光材质/网格选择。加载后直接列出模型内部名称，不需要重新搭建模型导入器。
- **编辑**：选中后使用编号挂点直接拖动；竖直箭头或 Shift 拖动只改高度，线段中间手柄只改该段下垂；二维可拖动挂点，并在属性中调整高度和下垂。支持整组移动、旋转、复制、删除、撤销/重做、保存和重开。
- **AI**：内置 AI 可创建或修改同一个参数化灯串对象，引用已发布模型 ID，经过宿主现有预览、确认、事务和撤销流程。

单组上限 2,000 颗、512 个悬挂点。空间不足时会显示实际灯数和原因，不伪装成达到要求的数量。重开和修改颜色不会重新生成随机种子。

## 开始使用

1. 打开本地编辑器左侧「灯串」。选择沿路径、缠绕或灌木随机。
2. 点击「灯头模型」打开带缩略图和名称的专用选择弹窗；自定义 GLB 先在现有模型库导入并确认入库，再从「从模型库添加」加入灯串专用收藏。收藏复用原文件，移出收藏不删除模型或已有灯串。灯头与安装形态独立选择；同一 S14 支持支线悬挂和灯座直连。
3. 点击「画灯串」，先点屋檐，再点栅栏。默认可以连接所有可见物体，不因事先选中的模型或当前楼层而限定目标。首点立即显示编号，第二点生成灯串，后续点击延长同一对象。点「完成并调整」、Enter、双击或 Esc 即结束并选中灯串。再画一条时点「画另一条灯串」。切换工具保留已落点部分，鼠标跟随预览不保存；⌘Z / Ctrl+Z 使用系统撤销。
4. 三维物体表面使用实际命中位置，并显示物体名和高度；细杆附近有 6 像素范围的表面捕捉。空处与「悬空挂点高度」所在平面求交，最后一次表面点击会更新此高度；Alt 临时自由放置。二维新挂点使用指定高度。仅需在单个模型上贴合或缠绕时，选模型后使用对应次要入口；「表面交互」仍可显式限定模型。缠绕/随机模式点击一次放置，灌木随机支持「在选中灌木布灯」；「创建示例」保留。
5. 选中灯串即可拖动编号挂点换位置；竖直箭头或 Shift 仅修改 Y，高度调整会解除该挂点的表面绑定；拖动「下垂」手柄只修改当前段。展开右侧属性面板可批量插入/删除挂点、输入精确数值，以及调整灯泡、灯距和颜色。高级外观参数默认折叠，所有选项保留。新增/删除保留其他挂点的模型绑定；统一修改下垂会替换单段覆盖。

本轮实景截图、保存数据与测试结果见 [屋檐到栅栏验收](docs/roof-fence-placement-2026-10-08.md)。

模型用于**单颗灯泡/重复单元**。若导入的是已经连成一整条的灯串，本插件会重复那整条模型，不会自动拆分；请先准备单元模型。发光部分需要按真实材质/网格名称标记，避免把夹子和灯座一起变色发光。

AI 示例：

> 在当前楼层原点创建一组灌木灯，区域 3×2×3 米，80 颗，红白交替，种子 43，不显示线。

> 把选中的灯串改成缠绕模式，高 3 米，底部和顶部半径都是 0.6 米，绕 5 圈，暖白色，保留随机种子。

> 把这条灯的数量改成 60 颗，其他参数不变。

## 当前边界

- 下垂是参数化视觉曲线。贴合/缠绕应用时检查所选宿主与灯线、灯头的相交；没有全场景持续绳索受力求解、自动碰撞绕障或自动避开所有树叶和枝条。
- 自由缠绕使用可编辑参数范围；A/B 表面缠绕使用实际表面查询。灌木按模型范围拟合椭球/长方体，附着的是整体分布区域，不代表每颗灯都落在实际叶片或枝条上。已验证导入物件缩放和内置树木高度跟随；更换模型、树种或拓扑变化不能保证继续对应，会提示重新布灯。
- 发光使用实例颜色和自发光材质。未给每颗灯创建真实点光源或阴影，不能把当前效果当作照度模拟。摆动是灯泡的视觉动画。
- 模型按静态 GLB 网格处理，不播放骨骼动画，不自动识别电路或连接拓扑。复杂模型重复大量实例仍受显卡性能限制。
- 本次约定范围内的升级已完成多轮本机浏览器验收；当前证据和验证限制见[验收核查](docs/acceptance-audit.md)。灌木按参考用途保留近似分布，不做逐叶精确贴合。键盘复制的页面验证受测试工具剪贴板限制；Windows、其他浏览器和独立 GLB 导出尚未验收。
- 当前插件接入了本地宿主新增的 AI 扩展接口，不是直接上传到公共 Pascal 网站就能使用的免集成插件包。

## 安装和开发

两个源码目录保持同级：

```text
workspace/
  editor-integration/
  string-lights-plugin/
```

在 `editor-integration` 执行：

```sh
bun install --frozen-lockfile
bun run --cwd apps/editor dev --port 3002
```

宿主通过 `file:../../../string-lights-plugin` 引用插件。`scripts/link-string-lights-plugin.ts` 在安装后创建包目录链接，避免 Bun 的逐文件链接触发 Turbopack 解析问题，并让插件复用宿主的依赖。Next 的编译根目录为两个目录的共同父目录；React、Three 和 R3F 使用宿主单例。

插件不打包 React/Three 副本、不接触账户密钥、不添加服务端路由。适配版本：当前宿主 `@pascal-app/{core,editor,viewer}` 1.0.1，Three 0.186，React 19。

UI 复用宿主 `ActionButton`、`ActionGroup`、`SegmentedControl`、`ToggleControl`、`SliderControl`、`PanelSection` 和 `PanelWrapper`。宿主 Tailwind 的 `@source` 包含本插件 `src`，确保开发和生产样式一致。立体图标随插件打包，来源和生成提示词见 [图标说明](src/assets/README.md)。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/schema.ts`、`commands.ts` | 参数、校验、统一创建/修改命令 |
| `src/layout.ts` | 路径采样、缠绕、随机分布、颜色和确定性种子 |
| `src/geometry.ts`、`renderer.tsx` | 内置/导入模型、实例渲染、材质、动画、资源释放 |
| `src/tool.tsx`、`handles.tsx`、`floorplan.ts` | 交互创建、挂点编辑、二维支持 |
| `src/support-operations.ts`、`support-edit.ts`、`support-editor.tsx`、`support-selection.ts` | 挂点批量插入与删除、绑定保留、场景预览、选中联动 |
| `src/controls.tsx`、`panel.tsx`、`catalog-panel.tsx` | 创建器与选中对象的属性面板 |
| `src/assets.ts` | 宿主已发布模型库的桥接 |
| `src/ai.ts` | AI 能力描述、模型引用、创建/修改适配 |
| `src/index.ts`、`definition.ts` | Pascal 插件、节点、能力和面板注册 |

宿主 AI 扩展公开入口是 `@pascal-app/editor/ai/plugins`。`registerAIPlugin({ id, describe, prepare })` 注册插件；AI 调用通用 `plugin_action`，插件只返回结构化创建/更新命令，最终仍由宿主场景适配器验证并提交。没有为灯串另做聊天窗口、模型供应商、自动确认或撤销系统。

2026-09-21 灯头与模型选择修订：专用图卡弹窗复用宿主 `@pascal-app/editor/ui/dialog`，通过 `setLightAssetCollectionHandler` 注入宿主模型收藏保存操作。收藏保存在模型记录 `collections` 中，保留统一入库、版本冲突检查、删除恢复和缩略图；AI 描述优先使用专用收藏。独立 `bulbHead` 和 `arrangement` 解耦模型和排列，旧场景没有这些字段时按旧 `style`/`paired` 渲染，避免改变已有作品。

随机参数：`sidePattern=random` 按 `leftProbability` 独立抽样左右（比例是概率，不承诺精确数量）；`branchAngle` 控制排列平面，`mountJitter` 控制每颗绕电线偏转，`angleJitter` 控制倾斜，`axialJitter` 控制灯头自转。后三项为对称 ± 范围，代码单位为弧度，UI 显示度。种子固定，改颜色不会重排。位置始终以主线接点及支线终点计算；灌木无电线。内置 C6 是程序化棱面近似；精确草莓纹、透明壳内灯芯、夹子和地插应由专用 GLB 单元提供。


产品规格约束：大小与沿线间距不再支持随机。旧 `sizeJitter`/`irregularity` 值读取时归零，AI 修改非零值会被拒绝。`smart` 默认关闭，普通款不显示随机颜色选项；关闭智能款时随机颜色回到固定轮换。自然程度 `naturalness` 总滑块只统一设置左右随机强度、绕线偏转、倾斜、自转、电线扰动和摆动，绝不更改尺寸、间距、数量、颜色或智能款状态。详细参数可在「详细自然设置」展开微调。沿线间距按实际线长采样；灌木仍使用无电线的随机区域布灯。
